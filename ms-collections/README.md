# MS COLLECTIONS — Premium Website + Enquiry Form

## Included
- `index.html`: complete website
- `style.css`: new forest-green, ivory and champagne-gold theme
- `script.js`: image gallery, search, photo viewer, and enquiry form
- `images/products/`: 25 actual jewellery photographs
- `images/hero-bracelet.png`: hero section bracelet photo

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser, or use VS Code Live Server.
4. No `npm install`, React or Node.js required.

## Enquiry form behaviour
The customer enters name, mobile number, category, optional photo number and message. On submit, the website opens WhatsApp to MS COLLECTIONS (`+91 93475 13231`) with the details prefilled. The customer must press Send in WhatsApp.
**This static version does not save enquiry records to a database or send them silently.** A database-backed enquiry inbox can be added later with a free-tier backend.

## Product images
The current 25 original product images are included and numbered in the gallery. They are shown as "Design 01" etc. Prices are not displayed. Product categories are left unclassified until the owner confirms which photos are chains or bracelets.
